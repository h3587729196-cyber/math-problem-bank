# 难题库 · 数学解题思路

一个把「题目」和「解题思路」都以**图片**保存的本地数学题库。不需要打公式，截图、拍照、粘贴就能收录；思路按步骤拆开存图，随时回看「当时卡在哪、怎么突破的」。

## 板块

| 板块 | 作用 |
| --- | --- |
| 题库 | 题干图片 + 一题多解（每组解法可独立命名、记录多条文字步骤、附一张思路图，并可标记「简易度：简单/适中/复杂」与「妙解」），支持标题/来源/难度/状态/标签/解法数/关键字筛选与搜索；另有独立的「破题思路」搜索池；详情页展示「用到的方法」 |
| 解法剧场 | 从题目详情一键进入：把任一解法按步骤逐帧回放，动画与页面无缝衔接、可随时打断；支持切换解法、拖动进度、倍速播放和键盘方向键操控 |
| 招式网络 | **方法与题库的力导向知识图谱（three.js 渲染）**：方法=蓝色发光球体（大=关联多、永远带标签），题目=状态色小球（绿/橙/红），关联=霓虹连线（核心亮蓝实线/辅助蓝虚线/延伸灰点线），方法共题=靛紫弧线、题目共法=青色弧线；三维力导向布局让"哪几招是一族、谁是枢纽"自然浮现；单击高亮邻域其余淡化，**双击飞入节点内部**——球体变半透明外壳，内部展开步骤链（琥珀色）/解法环（简易度着色）+ 邻居环绕，毛玻璃面板展示全部细节；阻尼惯性相机、空闲自动环绕、悬停辉光，Esc 返回全景 |
| 回看 | **FSRS-Lite 记忆模型 + 强制思考会话**：每个条目维护「难度 / 稳定性 / 记忆强度」，遗忘曲线 R(t)=(1+t/9S)⁻¹、目标保持率 90%；三级评分（忘了/有点模糊/做出来了）分别塌缩、微调、倍增间隔，到期排序按遗忘程度；**单卡专注会话——先强制想 20 秒**（环形倒计时，只给题目/方法，答案完全隐藏），倒计时结束才出现「查看答案」按钮，揭晓解法步骤/方法信号与易错点后再评分；评分后卡片弹簧飞出、下一张弹入；**连续做对 3 次自动毕业为「已解」**；方法掌握提升按同一模型排期，升到熟练自动退出；完成态圆环对勾动画 + 「即将到期」按天分组 || 认知回看 | 难度 4–5 的难题单独成池，按记忆曲线排期；**每次回看记录「这次觉得的难度」**（1–5 选择器），自动绘制**认知曲线**（难度随时间的变化，卡片与题目详情均展示）；觉得变简单了会降到当前感知难度并拉长间隔（降到 3 自动毕业），还是难保持高频；录入表单只保留一个难度字段 || 数据分析 | 专业学习报告：核心指标、状态趋势、攻克用时、薄弱点 Top、方法掌握度/难度/巧思/活跃度分析；可按「本月 / 近 90 天 / 全部 / 自定义」筛选，含上一期对比，按 A4 纸排版，一键打印/导出 PDF |
| 方法掌握度 | 每个方法可设置 5 级掌握度（了解 / 会用 / 熟练 / 精通 / 融会贯通），并自动按使用情况分类（新方法 / 高频 / 稳定 / 开始生疏 / 闲置），报告给出掌握度分布与建议重点练习列表 |
| 局域网同步 | 电脑与手机连同一 WiFi 时题库自动互通：数据存到本地服务端，新设备打开自动拉取，编辑后自动推送；备份面板也可手动「从其他设备合并 / 上传当前题库」 |
| 方法库 | 支持按名称/适用信号/标签/步骤/易错点模糊搜索；每个方法含适用信号、操作步骤、方法说明、易错点，支持上传示意图/笔记图；点击卡片进入专属详情视图，查看并管理关联题目 |
| 题↔方法关联 | 显式关联（存方法 ID，不受文字误差影响），每条关联带角色（核心/辅助/延伸）与备注，题目侧、方法侧双向管理 |
| 巧思库 | 所有解法里的破题步骤都可标星并设置巧妙程度（1–5 档），标星步骤自动汇入巧思库；支持模糊搜索、按程度排序，可就地取消收藏、调整程度或删除，点击条目可溯源回原题目 |
| 标签 | 题目与方法共用一套标签，支持重命名、删除（批量生效）；重命名成已有标签时会先确认再合并 |
| 备份 | 本地自动备份：选一个电脑文件夹，打开应用或修改题目后自动保存完整备份，只保留最近 N 份；另支持手动导出/导入（ZIP 含全部图片原图），备份内含页面设置（主题 / 本地自动备份），导入可选「合并（保留现有）」或「替换（删除现有）」，并提供「一键清空全部数据」，兼容旧版 JSON 备份 |

## 设计语言（Liquid · Apple 级）

- **液态玻璃（水珠 + 自然折射）**：核心是**晶莹剔透的水珠**——玻璃控件如一滴水浮在页面上：顶部高光点（水滴反光）、底部透光（caustic）、菲涅尔亮边（rim light）、接触阴影（水珠坐在表面），玻璃更清透（少雾面）；**自然折射次之**——SDF 位移图 + `feDisplacementMap` 让背景像素在边缘带被拉向中心（透镜感），`backdrop-filter: url(#lq-lens) blur() saturate() contrast() brightness()`，不支持 `url()` 的浏览器自动回退纯模糊；玻璃只用于导航/控件层，内容保持实底；- **动效**：视图切换模糊+视差弹性过渡、卡片 hover 三层阴影抬升 + 图片缩放、按钮光泽扫过、网格 stagger 入场、分段控件滑动胶囊、评分卡片弹簧飞出、完成圆环描画，减动效全降级；
- **色彩**：品牌渐变（蓝→靛→紫）用于 logo/悬浮按钮，页面头 hero 光晕背景，iOS 原色状态体系，明暗双主题严格一致；

## 技术栈

- React 19 + TypeScript + Vite
- [Motion](https://motion.dev)（Framer Motion 的继任包）提供弹簧与手势动效
- [Three.js](https://threejs.org)（招式网络三维引擎：PBR 金属材质、环境反射、UnrealBloom 泛光，按需加载，不影响首屏）
- IndexedDB：题目/方法/图片 Blob 全部保存在**本机浏览器**，无后端、无上传

## 本地运行

```bash
npm install
npm run dev        # 开发模式，默认 http://localhost:5173
npm run build      # 类型检查 + 生产构建
npm run preview    # 预览生产构建
npm run serve      # 本地部署：零依赖静态服务，默认 http://localhost:5173
```

打开 [http://localhost:5173](http://localhost:5173) 即用。首次打开会自动写入 3 道预置题和 3 条预置方法，不需要时可在「备份与恢复」一键清空。

## 本地部署

想要脱离开发模式、像普通程序一样在本地跑，双击项目根目录的 **`启动本地版.bat`** 即可：它会自动构建生产版本、启动本地服务并打开浏览器。

- 服务默认端口与开发模式相同（5173），所以**数据（IndexedDB）与开发模式互通**，不丢题；
- 若 5173 已被占用（例如开发服务器还在运行），会自动顺延到 5174、5175…并自动打开浏览器，无需手动处理；
- 也可以用命令行 `npm run serve`（或 `PORT=4173 npm run serve` 换端口）；

## 数据说明

- 所有数据（含图片）存在浏览器 IndexedDB（数据库名 `math-problem-bank`），不经过任何服务器；
- 录入图片时会自动压缩（最长边 1920px、质量 0.85），大幅减小存储占用；SVG/GIF 保持原样；
- 侧栏「备份与恢复」可导出完整备份（ZIP，含图片原图），导入前会预览将覆盖多少道题/方法，导出与导入都有进度条；也兼容导入旧版 JSON 备份；
- 超过 7 天没有备份时，题库顶部会出现备份提醒；
- 「备份与恢复」里可开启本地自动备份：选择一个电脑文件夹后，打开应用或修改题目 30 秒后会自动把完整备份存进去（保留最近 5/10/20/50 份可选），无需手动导出；
- 题目详情右上角的下载按钮可把该题全部图片原图导出到本地文件夹（Chrome/Edge 支持，选择文件夹即可）；文件名带题目 ID 前缀，避免不同题目重名覆盖；不支持文件夹导出的浏览器会改为逐张下载并提示；
- 文字只用于元数据（标题、来源、标签、步骤说明），题目与思路本体均为图片。

## 自动化验证

需要先启动开发服务器（`npm run dev`），然后：

```bash
npm run check
```

- `scripts/audit.mjs`：无头 Chrome 检查图片加载、布局溢出、毛玻璃/降级、深色模式、弹层几何、移动端适配等 20 项指标；
- `scripts/e2e.mjs`：完整走一遍新增→改状态→编辑→删除→搜索→新建方法→标签重命名/删除→ZIP 备份导出/替换导入→删除方法清理关联→破题思路独立搜索池→一题多解→回看池顺延→低掌握度方法回看→解法剧场→招式网络→认知回看排期与毕业→数据分析报告页（含自定义区间、上一期对比、方法掌握度）→手机访问二维码→局域网同步入口。

脚本默认使用 Chrome，可用第二个参数指定浏览器路径，例如：

```bash
node scripts/e2e.mjs "C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe"
```

## 交互提示

- 新增/编辑题目：题干必须有图片；「破题思路」用多条文字步骤记录（切入点、卡点、关键转折）；另外可以附一张思路示意图（重复上传会替换，只保留一张）；
- 建议先在「备份与恢复」里选择备份文件夹并开启自动备份，数据修改后会自动存到本地文件夹，不怕丢；
- 支持一题多解：点「添加另一种解法」即可新增一组解法，每组可独立命名（如“判别式法”“数形结合”）、记步骤、附图；空解法保存时会自动丢弃；
- 破题步骤可以点星标收藏，并设置巧妙程度 1–5；标星步骤自动进入侧栏「巧思库」，支持模糊搜索、按程度排序，可就地取消收藏、调整程度或删除，点击任意条目即可溯源回原题目；
- 题库搜索区可以切换「常规搜索 / 破题思路」两个池：破题思路池只匹配思路步骤里的文字，与标题、来源、标签搜索完全分开，结果按题目的标签分组（带多个标签的思路会出现在多个分组里）；
- 题库可按「解法数」筛选：全部 / 1 个解法 / 2 个解法 / 3 个解法及以上 / 暂无解法，破题思路池同样生效；
- 每组解法可设置两个维度：「简易度」（简单 / 适中 / 复杂）和「妙解」开关；详情页以徽章展示，数据分析报告新增「解法分析」（简易度分布与妙解占比）；
- 解法剧场：题目详情点「解法剧场」即进入逐步骤回放，顶部可切换解法，底部进度条可拖动，支持 1×/1.5×/2× 倍速，键盘 ← → 切换步骤、Space 播放/暂停；动画使用弹簧动效，并遵循系统「减少动态效果」设置；
- 招式网络：侧栏「招式网络」或手机端底部标签进入（three.js 按需加载）；方法=蓝色发光球体（大=关联多、永远带标签），题目=状态色小球，关联=霓虹连线按角色区分（核心实线/辅助虚线/延伸点线），方法共题=靛紫弧线；力导向布局自动聚类，枢纽居中；**单击高亮邻域**（其余淡化）、**双击飞入节点内部结构**（球体变半透明外壳，内部展开步骤链/解法环 + 邻居环绕），毛玻璃解剖面板展示信号/步骤/易错点/图片/解法，Esc 飞回全景；支持筛选/搜索定位/拖拽节点/旋转缩放/适配画布，增删后实时重组；
- 认知回看：难度 4–5 的题自动进入独立池子，首次排期 3 天后；到期后点「这次觉得简单了」会降 1 档难度并拉长间隔（降到 3 时自动毕业），点「还是难」保持高频（1 天后）；录入时可填「当时觉得难度」，回看卡片会对比显示「变简单 / 变难 / 认知没变」；
- 界面布局优化：筛选栏统一排版（手机端自动全宽/双列）、卡片网格间距与列宽更舒适；
- 回看采用 FSRS-Lite 记忆模型：每个条目有「难度 / 稳定性 / 记忆强度」，目标保持率 90%；卡上实时显示当前记忆强度，三个评分按钮直接预告各自的下次间隔；**连续做对 3 次自动毕业为「已解」**；到期的按遗忘程度排序（忘得最多的先复习）；完成后「即将到期」按天分组展示；
- 回看采用 FSRS-Lite 记忆模型：每个条目有「难度 / 稳定性 / 记忆强度」，目标保持率 90%；卡上实时显示当前记忆强度，三个评分按钮直接预告各自的下次间隔；**连续做对 3 次自动毕业为「已解」**；到期的按遗忘程度排序（忘得最多的先复习）；完成后「即将到期」按天分组展示；
- 回看页顶部汇总“今日到期 X 道题 · Y 个方法”，逾期超过 1 天的卡片标红提示，按“逾期天数 + 难度/掌握度”排序；
- 侧栏「数据分析」会生成本地专业报告：核心指标、近 12 周趋势、攻克用时榜、薄弱标签 Top5、方法/难度/巧思/活跃度分析；顶部可切换「本月 / 近 90 天 / 全部」，页面按 A4 纸面设计，点「打印 / 导出 PDF」即可打印；
- 报告按 Apple 文档风格排版：带编号与英文眉题的章节、大字号 KPI、右对齐细线表格、浅网格趋势图，打印时保留全部颜色，A4 输出更专业；
- 报告支持「自定义」日期区间，并自动对比上一期（新增 / 攻克 / 回看按时完成率变化）；
- 编辑方法时可设置掌握度（了解 / 会用 / 熟练 / 精通 / 融会贯通），卡片与详情展示；报告会按使用情况自动分类方法（新方法 / 高频使用 / 稳定使用 / 开始生疏 / 闲置未用）并列出「建议重点练习」；
- 手机端为苹果风格底部标签栏：题库 / 回看 / 分析 / 巧思 / 方法 / 标签 + 备份入口，右下角悬浮「新增题目」按钮，卡片与报告自动适配窄屏；
- 侧栏「手机访问」会生成二维码：手机连同一 WiFi 扫码即可在手机浏览器打开题库，并显示访问地址（可一键复制）；
- 电脑与手机连同一 WiFi 时，题库会自动互通：全新设备（手机）打开会自动用电脑的题库替换预置数据，编辑后约 30 秒自动推送到本地服务；「备份与恢复」里可手动「从其他设备合并 / 上传当前题库」；
- 电脑端不会弹出“其他设备有更新”的同步提醒（手机端仍会提示），避免打扰；需要合并时可在「备份与恢复 → 局域网同步」手动操作；
- 导出的备份会包含页面上的设置信息（主题、本地自动备份），导入时随数据一起恢复；
- 手机端动画优化：底部标签栏带滑动胶囊高亮、页面切换轻量淡入、按钮按压缩放，并遵循系统「减少动态效果」设置；
- 「备份与恢复」底部有「清空全部数据」：一键永久删除所有题目、方法与统计日志（会先弹确认，建议先导出备份）；
- 攻克用时、回看完成率、活跃时段等数据从启用日志功能后开始统计（之前的历史题目无法回溯用时），其余快照类指标基于全部题目；
- 方法也支持图片：示意图、公式笔记、参考截图都能挂到方法上（拖入、选择或 Ctrl+V），卡片和详情都会展示；
- 新增/编辑题目时可在「关联方法」区把题目显式挂到方法上：搜索式选择器支持按名称/信号/标签模糊搜索、按题目标签推荐候选、可多选；找不到的方法可以当场「新建方法并关联」；
- 剪贴板里截了题就直接 `Ctrl+V`，自动成为思路图；
- 卡片状态三态：待做 / 已解 / 卡住，卡住的题就是下次优先攻克的；
- 列表超过 24 条后会自动出现「显示更多」，避免一次渲染太多卡片；
- 标签重命名时如果新名字已存在，会先确认「合并」再执行；
- 方法库里写清「什么时候想到它」，点卡片查看完整详情：信号、步骤、易错点与所有关联题目；
- 方法详情里可直接搜索并添加关联题目，也能就地改角色、写备注、移除关联。
